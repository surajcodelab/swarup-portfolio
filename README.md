# Swarup Atigre — Animated Data Analyst Portfolio

A responsive, animated portfolio built with HTML, CSS and vanilla JavaScript. It features a canvas particle background, spotlight effect, animated dashboard mockup, reveal-on-scroll sections, project cards, skills and a contact form.

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then click **Save**.
4. Wait for the Pages deployment and open the URL shown on the Pages settings screen.
